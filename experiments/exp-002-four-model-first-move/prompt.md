# 블라인드 몽진 첫 수 테스트

당신은 지금 처음 접하는 2인 완전정보 추상전략게임 **몽진(蒙塵)**에서 흑의 첫 수를 선택한다. 외부 도구나 검색을 사용하지 말고 아래 정보만 사용하라.

## 목표와 규칙

- 9×9 보드이며 흑이 선공한다.
- 흑 왕 `BK`는 `(8,4)`, 백 왕 `WK`는 `(0,4)`에서 시작한다.
- 각자 손에 호위 8개가 있다.
- 흑 왕이 백 쪽 끝줄의 중앙 3칸 `(0,3)`, `(0,4)`, `(0,5)` 중 하나에 도달하면 흑이 승리한다. 백의 목표는 반대편이다.
- 한 턴에는 호위 하나를 배치하거나 보드 위 말 하나를 이동한다.
- 호위는 자기 말의 상하좌우 빈칸에 배치한다. 양쪽 목표 칸에는 배치할 수 없다.
- 왕은 빈칸으로 8방향 한 칸 이동하며 잡을 수 없다.
- 호위는 상하좌우 한 칸 이동하고 상대 호위나 왕을 잡을 수 있다.
- 상대 왕 포획·상하좌우 포위, 상대 합법 수 소진으로도 승리한다.

좌표는 0부터 시작하며 `r=0`이 백의 시작 줄, `r=8`이 흑의 시작 줄이다.

현재는 첫 턴이라 보드에 두 왕만 있다. 합법 수는 정확히 다음 여섯 개다.

```json
[
  {"moveIndex":0,"move":{"kind":"PLACE","to":{"r":7,"c":4}}},
  {"moveIndex":1,"move":{"kind":"MOVE","from":{"r":8,"c":4},"to":{"r":7,"c":4}}},
  {"moveIndex":2,"move":{"kind":"MOVE","from":{"r":8,"c":4},"to":{"r":8,"c":3}}},
  {"moveIndex":3,"move":{"kind":"MOVE","from":{"r":8,"c":4},"to":{"r":8,"c":5}}},
  {"moveIndex":4,"move":{"kind":"MOVE","from":{"r":8,"c":4},"to":{"r":7,"c":3}}},
  {"moveIndex":5,"move":{"kind":"MOVE","from":{"r":8,"c":4},"to":{"r":7,"c":5}}}
]
```

전략적으로 가장 낫다고 판단하는 수 하나를 고르라. 숨겨진 사고 과정은 쓰지 말고 판단 근거를 한국어 1~3문장으로 요약하라. 다음 스키마의 JSON 객체만 출력하고 마크다운 코드 펜스나 추가 설명은 쓰지 마라.

```json
{
  "moveIndex": 0,
  "reasoningSummaryKo": "판단 근거 요약",
  "strategicIdea": "guard-development",
  "confidence": 0.0
}
```

`strategicIdea`는 `guard-development`, `king-advance`, `king-side-step`, `other` 중 하나여야 한다. `moveIndex`는 위 여섯 합법 수에 표시한 0~5 중 하나여야 한다.
