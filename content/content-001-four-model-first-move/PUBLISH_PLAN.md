# CONTENT-001 발행 계획

## 발행 목표

첫 발행의 목적은 큰 반응을 즉시 만드는 것이 아니라 다음 세 가지를 확인하는 것입니다.

1. 몽진을 처음 보는 사람이 게임의 목표를 한 문장으로 이해하는지
2. 네 AI가 같은 첫 수를 골랐다는 결과가 흥미롭게 전달되는지
3. 공개 실험 기록까지 확인하려는 독자가 어느 채널에서 생기는지

댓글이나 투표 참여를 전제로 하지 않습니다. 반응이 적어도 다음 Codex 완주
대국은 계획대로 진행합니다.

## X 발행 방법

1. 새 게시물 작성 화면에서 `SOCIAL.md`의 X 1/4 문안을 붙여 넣습니다.
2. `assets/result-board.png` 한 장을 첨부하고 위의 대체 텍스트를 입력합니다.
3. 연결 게시물 추가 버튼으로 2/4, 3/4, 4/4를 순서대로 추가합니다.
4. 링크는 4/4에만 둡니다. 첫 게시물은 게임 설명과 결과 이미지에 집중합니다.
5. 네 문안과 이미지가 맞는지 미리 본 뒤 전체 게시 기능으로 한 번에 발행합니다.
6. 모델 공식 계정은 태그하지 않습니다. 이번 콘텐츠는 비교 결과 공개이지
   모델 회사의 반응을 요청하는 게시물이 아닙니다.

일반 X 게시물은 280자까지 작성할 수 있고 사진은 최대 4개까지 첨부할 수
있습니다. 이번 문안은 무료 계정에서도 사용할 수 있도록 모든 게시물을 280자
이내로 유지합니다. 16:9 단일 이미지는 X가 안내한 단일 사진 표시 비율 범위
안에 들어갑니다.

## Threads 발행 방법

1. `SOCIAL.md`의 Threads 본문을 새 게시물에 붙여 넣습니다.
2. `assets/result-board.png`를 첨부합니다.
3. 작성 화면에 관련 주제 추가가 표시되면 `인공지능`을 우선 사용하고,
   해당 주제가 없으면 `인디게임`을 사용합니다. 해시태그를 여러 개 나열하지 않습니다.
4. 본문을 발행한 뒤 첫 답글로 전체 기록 링크와 다음 Codex 완주 실험을 남깁니다.
5. X 문안을 그대로 복사하지 않습니다. Threads에서는 한 게시물 안에서 게임
   설명, 참가 모델, 결과, 한계를 모두 읽을 수 있게 합니다.

Threads 기본 게시물은 최대 500자이며 링크와 사진을 포함할 수 있습니다.
10,000자 텍스트 첨부 기능도 있지만 이번 콘텐츠에는 사용하지 않습니다. 짧은
본문과 이미지로 결과를 먼저 전달하고 상세 내용은 링크로 분리합니다.

## 발행 전 최종 확인

- 이미지가 Studio ZZG 포레스트·바닐라 팔레트인지 확인합니다.
- 각 채널의 첫 게시물에서 몽진이 어떤 게임인지 설명합니다.
- Claude가 예산 문제로 미구독 상태라 제외됐다고 명시합니다.
- 네 모델의 선택, 자신감, 합법 여부가 `normalized/summary.json`과 일치합니다.
- “최고”, “승자”, “벤치마크 우승” 같은 표현을 사용하지 않습니다.
- 투표, 댓글 요청, 억지 질문형 CTA를 넣지 않습니다.
- X 이미지에 대체 텍스트를 입력합니다.
- 링크를 로그아웃 창에서도 열어 봅니다.

## 성과 기록 원칙

첫 콘텐츠는 절대 수치를 기준선으로 저장합니다. 성공·실패를 바로 판정하지
않고 세 번째 콘텐츠까지 같은 항목을 쌓은 뒤 비교합니다.

- 공통: 게시물 URL, 게시 시각, 첨부 이미지, 실제 사용 문안
